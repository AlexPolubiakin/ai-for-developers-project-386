# AI Project Documentation

## Структура папки `ai/`

| Файл | Назначение |
|------|-----------|
| `README.md` | Этот файл. Правила работы с AI-папкой |
| `progress.md` | Чеклист прогресса по шагам из плана |
| `sessions.md` | Лог каждой рабочей сессии с AI |
| `project-mvp-plan.md` | Полная спецификация MVP |

## Правила работы

### Сессии

**Каждая сессия работы с AI фиксируется в `sessions.md`.**

Формат записи:

```markdown
## Сессия N — YYYY-MM-DD

### Цель
Кратко: что планировали сделать

### Что сделали
- Конкретные действия
- Созданные/изменённые файлы

### Решения
- Принятые архитектурные решения
- Обоснования выборов

### Следующий шаг
Что делаем в следующей сессии
```

### Прогресс

`progress.md` ведётся как чеклист. После завершения каждого шага обновляем статус:
- `[ ]` — не начат
- `[~]` — в процессе
- `[x]` — завершён

### MVP-план

`project-mvp-plan.md` — живой документ. Обновляется при изменении архитектуры или скоупа.

### API-контракт

Хранится в `api-contract/`. TypeSpec-файлы — единственный источник правды для API. При изменении API сначала обновляем TypeSpec, потом реализацию.

## Стек проекта

- **Frontend**: React + Vite + Mantine UI + TypeScript
- **Backend**: NestJS + Prisma + TypeScript
- **Database**: PostgreSQL
- **Testing**: Jest (backend), Vitest + Testing Library (frontend), Playwright (E2E)
- **Infrastructure**: Docker Compose
